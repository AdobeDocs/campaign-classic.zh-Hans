# 隐私数据保护条例{#general-data-protection-regulation-gdpr}



默认情况下，下面详细介绍的工作流将与&#x200B;**隐私数据保护条例**&#x200B;模块一起安装。 有关此模块的详细信息，请参阅此[文章](https://helpx.adobe.com/cn/campaign/kb/acc-privacy.html)。

 <tbody> 
  <tr>

  </tr> 
  <tr>

  </tr>
